# Governance

## Maintainer

Mellouki Jamal is the project maintainer and has final responsibility for
releases, licensing, and security responses.

## Decisions

Small changes are decided in pull requests. Changes to the public API, file
format, supported platform set, or dependency policy require an issue or an
RFC in `docs/adr/`.

An RFC is accepted when the maintainer approves it and no unresolved objection
remains. Accepted RFCs are recorded with their date and status.

## Contributing

Contributors are credited in `CHANGELOG.md` and in release notes. Commit
sign-off is required; see `CONTRIBUTING.md`.

## Releases

Releases follow Semantic Versioning. Until `1.0`, minor versions may change
the public API. Security releases may be made from the latest supported line.
